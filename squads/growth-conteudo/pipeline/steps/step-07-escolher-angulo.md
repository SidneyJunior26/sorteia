# Step 7: Escolher Ângulo do Ciclo (checkpoint)

O usuário escolhe UM dos 4-6 ângulos gerados pelo Ivo Instagram para desenvolver nos 3 formatos deste ciclo (Instagram Reels, Instagram Feed e TikTok).

## Contexto a apresentar ao usuário

"Revise os ângulos completos em `squads/growth-conteudo/output/angles.md`. Cada ângulo já foi pensado para servir os 3 formatos do ciclo."

Listar os ângulos gerados em formato numerado, cada um com: título, pilar, gatilho psicológico dominante.

## Pergunta ao usuário (lista numerada)

```
Qual ângulo você quer desenvolver neste ciclo?

1. [Título do ângulo 1] — Pilar: [pilar] — Gatilho: [gatilho]
2. [Título do ângulo 2] — Pilar: [pilar] — Gatilho: [gatilho]
3. [Título do ângulo 3] — Pilar: [pilar] — Gatilho: [gatilho]
...
N. Gerar novos ângulos (volta para o step 6)
```

## Após a resposta

Salvar em `squads/growth-conteudo/output/angle-selection.md`:

```markdown
# Angle Selection

**Ângulo escolhido:** {título}
**Pilar:** {pilar}
**Gatilho psicológico dominante:** {gatilho}
**Execução sugerida (copiada de angles.md):** {texto completo do ângulo escolhido}
**Data:** {YYYY-MM-DD}
```

Este arquivo é o `inputFile` dos steps 8 (Reels), 9 (Feed) e 10 (TikTok).
