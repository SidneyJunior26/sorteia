# Quality Criteria — Growth Conteúdo (Achei Meu Livro)

Critérios objetivos usados pela Vera Veredito na revisão e por cada agente criador como autocheck antes de entregar. Compilado a partir de `researching.md`, `copywriting.md`, `instagram-reels.md`, `instagram-feed.md`, `image-design.md` e `review.md`.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## Pesquisa (Rita Referência)

- [ ] Todo achado tem fonte com URL/nome rastreável e data de acesso
- [ ] Nível de confiança (alta/média/baixa) atribuído a cada achado
- [ ] Pelo menos 2 fontes independentes corroboram cada achado de alta confiança
- [ ] Ângulos de tendência incluem avaliação de ciclo de vida (emergente/crescimento/maduro/declinando)
- [ ] Seção de gaps preenchida, mesmo que pequena
- [ ] Nenhuma opinião apresentada como fato

## Estratégia e Calendário (Gustavo Growth)

- [ ] Pelo menos 1-2 pilares de conteúdo priorizados por ciclo (nunca todos ao mesmo tempo)
- [ ] Calendário tem formato, plataforma e tema por peça, sem ambiguidade
- [ ] Métrica de sucesso do ciclo é específica e mensurável (save rate, retenção 3s, ou CTR — nunca "engajamento" genérico)
- [ ] Qualquer ajuste ao roadmap existente é justificado com o achado da pesquisa que motivou a mudança
- [ ] Recursos/tempo necessários são realistas para operação solo (usuário sem experiência prévia em marketing)

## Copy e Ângulos (Ivo Instagram, Tais TikTok)

- [ ] Hook entregue nos primeiros 1-2 segundos (vídeo) ou 125 caracteres visíveis (legenda)
- [ ] 3 opções de hook apresentadas antes do corpo, cada uma com gatilho psicológico distinto
- [ ] Nível de consciência do público calibrado para "não-consciente"/desconhece o produto (conteúdo de aquisição, não retenção)
- [ ] CTA presente, específico e de intensidade calibrada (leve para topo de funil — salvar/seguir, nunca "compre agora")
- [ ] Nenhum clichê da lista "never use" aparece no texto final
- [ ] Copy Stress Test aplicado (teste do cético, corte de 15-25% de palavras de enchimento)
- [ ] Acentuação completa em português em todo o texto
- [ ] Nenhuma promessa de clique/resultado numérico específico é feita ao público (apenas internamente, como cenário)

## Vídeo (Reels/TikTok)

- [ ] Hook nos primeiros 2 segundos, sem introdução lenta/logo/"oi gente"
- [ ] Duração entre 15-30s para retenção ótima
- [ ] Legendas embutidas (85% assiste sem som)
- [ ] Corte visual a cada 3-5 segundos
- [ ] Final desenhado para loop (conexão visual/narrativa com o início)
- [ ] CTA específico no fechamento

## Carrossel/Feed

- [ ] Formato de carrossel escolhido explicitamente (Editorial, Listicle, Tutorial, Mito vs Realidade, Antes/Depois, Storytelling, Problema→Solução)
- [ ] Slide de capa provocativo, para o scroll
- [ ] Cada slide com hierarquia de duas camadas (headline + texto de apoio), 40-80 palavras
- [ ] Cores de fundo alternadas entre slides
- [ ] Nenhum contador de slide (ex: "3/8") nas imagens

## Visual (Duda Design)

- [ ] Design system documentado antes das peças individuais (cores, tipografia, espaçamento)
- [ ] HTML autocontido (CSS inline, sem CDN externo além de Google Fonts)
- [ ] Tamanho de fonte mínimo respeitado por plataforma (nunca abaixo de 20px)
- [ ] Contraste mínimo WCAG AA (4,5:1)
- [ ] Primeira peça renderizada e verificada visualmente antes do lote completo
- [ ] Nenhum texto placeholder ("Lorem ipsum", "Texto aqui") no entregável final

## Revisão (Vera Veredito)

- [ ] Todo score tem justificativa por escrito
- [ ] Qualquer critério abaixo de 4/10 dispara REJECT automático, independente da média
- [ ] Toda rejeição inclui correção específica (o quê, onde, como)
- [ ] Copy e visual avaliados juntos, nunca isoladamente
- [ ] Veredito final é inequívoco: APPROVE, CONDITIONAL APPROVE ou REJECT

## Publicação (Paulo Publica)

- [ ] Dry-run executado e aprovado antes de qualquer publicação ao vivo
- [ ] Confirmação explícita do usuário recebida antes do publish live (dry-run não é confirmação)
- [ ] Preview estruturado apresentado (plataforma, imagens/vídeo, legenda, hashtags, status de validação)
- [ ] Publicação sequencial (nunca em paralelo) com relatório por plataforma
- [ ] Toda publicação bem-sucedida inclui URL/permalink do post
